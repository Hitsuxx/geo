Lecture 1 — Geological Structures & Tectonics
🔄 Rock Cycle
MEDIUM
▾

💡 The Idea

Rocks continuously transform between three types: igneous, sedimentary, and metamorphic. No rock is permanent.

🏗️ Why Engineers Care

  • Rock type determines strength, permeability, weathering
  • Understanding origin predicts engineering properties
  • Foundation design depends on rock cycle history
🦴

Caveman version: Rock melt → cool = igneous. Rock break tiny → pile up → squeeze = sedimentary. Rock get squished/heated but not melted = metamorphic. Then start over. Rock... never die. Just change shape.

Click arrows to see processes

📌 Memory Box

  • Igneous = cooled magma (intrusive = slow = big crystals; extrusive = fast = small)
  • Sedimentary = particles compressed + cemented
  • Metamorphic = existing rock changed by P & T (not melted)
  • Rock cycle connects all three via melting, erosion, burial
📐 Strike, Dip & Apparent Dip
🔥 HIGH PRIORITY
▾

💡 The Idea

  • Strike: Direction of horizontal line on inclined plane (like shoreline on a tilted beach)
  • Dip: Maximum angle of inclination (steepest slope direction)
  • Apparent dip: Dip you SEE in a cross-section that is NOT perpendicular to strike — always less than true dip
tan(αapparent) = tan(αtrue) × cos(β)
αapparent = apparent dip angle
αtrue = true dip angle
β = angle between section direction and dip direction

⚠️ Exam Trap

  • Apparent dip is always less than or equal to true dip
  • If β=0° (section ⊥ strike): apparent = true dip
  • If β=90° (section ∥ strike): apparent dip = 0°
✅ Worked Example

True dip = 30°, β = 40°

tan(apparent) = tan(30°) × cos(40°)

= 0.577 × 0.766 = 0.442

Apparent dip = 23.8°

Strike = horizontal line on bedding plane
🦴

Strike = direction you walk on tilted rock to stay at same height. True dip = steepest slope. Apparent dip = what you see if you cut the rock at an angle — always looks less steep!

🧠 Quick Quiz: A plane has true dip = 45° and you measure apparent dip in a section at β = 60° to dip direction. Apparent dip is:

📌 Memory Box — Strike & Dip

  • Strike ⊥ to dip direction (always at right angles)
  • True dip = steepest possible dip on that plane
  • Apparent dip < true dip (always, except when section ⊥ strike)
  • Formula: tan(app) = tan(true) × cos(β)
  • β = angle between section and dip direction
⚡ Faults — Types & Recognition
🔥 HIGH PRIORITY
▾

💡 Key Vocabulary

  • Fault plane = surface of movement
  • Hanging wall = block above the fault plane
  • Footwall = block below the fault plane
  • Throw = vertical displacement
  • Heave = horizontal displacement

⬇️ Normal Fault

  • Hanging wall moves DOWN
  • Caused by extension/tension
  • Rift valleys, divergent plates

⬆️ Reverse / Thrust Fault

  • Hanging wall moves UP
  • Caused by compression
  • Mountain building, convergent plates
  • Thrust fault = reverse fault at low angle (<30°)

↔️ Strike-Slip Fault

  • Movement is horizontal
  • Transform boundaries
  • San Andreas Fault (famous example)
  • Also called: transcurrent fault

🎯 Exam Recognition — How to Identify Faults

  • Normal fault: Hanging wall DOWN. Strata appear missing (extension = beds spread apart)
  • Reverse fault: Hanging wall UP. Strata appear repeated (compression = beds overlap)
  • Strike-slip: Horizontal offset. Map view shows lateral displacement of features
  • Key tip: On geological maps, fault = thick red/black line; beds on each side displaced
🧠 In a geological cross-section you notice the same limestone bed appears TWICE on one side of a fault. What type of fault is this?

📌 Fault Memory Box

  • Normal = HW down = EXTENSION = rifting
  • Reverse = HW up = COMPRESSION = mountain building
  • Thrust = reverse at low angle (<30°) = same cause
  • Strike-slip = horizontal = transform boundary
  • Hanging wall = block ABOVE fault plane
  • Normal fault → beds MISSING; Reverse → beds REPEATED
🌊 Folds — Anticlines & Synclines
🔥 HIGH PRIORITY
▾

💡 Key Types

  • Anticline = arched upward (∩). Oldest rocks in core/centre
  • Syncline = arched downward (∪). Youngest rocks in core/centre
  • Plunging fold = fold axis is inclined (not horizontal)

⚠️ Critical Exam Rule

Anticline: Beds DIP AWAY from the core → oldest in middle

Syncline: Beds DIP TOWARD the core → youngest in middle

🦴

Anticline = mountain shape. Rock layers point away like a tent. Old rocks inside. Syncline = valley shape. Layers point inward like a bowl. New rocks inside.

📌 Fold Memory Box

  • ANTI-cline = ANTI-gravity = arches UP = oldest in middle
  • SYN-cline = SYNks down = bowl shape = youngest in middle
  • Plunging fold = axis tilted = on map, beds form V or U patterns
  • Mendip Hills = series of E-W trending periclines (Carboniferous Limestone)
📏 Unconformities & Relative Age Rules
🔥 HIGH PRIORITY
▾

💡 What is an Unconformity?

A time gap in the geological record — older rocks eroded before younger rocks deposited on top. Represents missing time.

Types of Unconformity

  • Angular unconformity: beds below tilted at different angle to beds above
  • Disconformity: both sets parallel but time gap exists
  • Nonconformity: sedimentary on igneous/metamorphic

📋 Relative Age Rules (Steno's Laws)

  1. Superposition: Older beds are BELOW younger beds
  2. Original horizontality: Beds deposited horizontally
  3. Lateral continuity: Beds extend laterally until thinning
  4. Cross-cutting: Features that cut others are younger (faults, dykes)
  5. Inclusions: Included fragments are older than the rock containing them

🎯 How to Reconstruct Geological History

  1. Identify oldest beds (bottom) → list oldest to youngest
  2. Identify unconformities (gap in record)
  3. Identify folds (formed before unconformity if below it)
  4. Identify faults (cross-cutting = younger than what they cut)
  5. Identify intrusions (younger than cut rocks)
🦴

Old rocks get folded, then tilted. Then big erosion happen — rocks disappear. New flat rocks plop on top. Flat rocks on tilted rocks = UNCONFORMITY. Missing time!

🧠 In a geological section, a dyke cuts through both folded limestone beds AND an overlying horizontal sandstone. The dyke is:

📌 Unconformity Memory Box

  • Unconformity = TIME GAP + erosion surface
  • Angular = tilted beds below + flat beds above (most common in exams)
  • Cross-cutting = YOUNGER (faults, dykes cut through older things)
  • Superposition = OLDEST at BOTTOM (normal sequence)
  • History: deposit → fold/tilt → erode → deposit again = angular unconformity

🗺️ Geological Maps, True Dip & Thickness
🔥 HIGH PRIORITY
▾

📐 Thickness of Strata Formula

t = w × sin(δ)
t = true thickness of layer
w = width of outcrop (measured ⊥ to strike)
δ = true dip angle
For inclined ground surface:
t = w × (sin δ cos α ± cos δ sin α)
α = ground surface slope angle
+ if dip and ground slope in same direction
− if dipping opposite to ground

🗺️ Reading Geological Maps

  • V-rule: outcrop width shows dip. V-shape of beds in valleys points UPSTREAM if dip < valley slope
  • Unconformity = distinct contact with angular discordance
  • Faults = thick lines (usually red/black), offset beds
  • Strike lines = contours on a geological surface
✅ Worked Example — Thickness

Outcrop width (map) = 80m

True dip = 35°

t = 80 × sin(35°)

= 80 × 0.574

t = 45.9 m

🎯 Exam Recognition — 3-Point Problem

Given 3 borehole depths to same bed → find strike and dip:

  1. Plot boreholes on map with depth values
  2. Interpolate to find equal-elevation points on the bed
  3. Draw strike lines (join equal elevations)
  4. Measure perpendicular distance for dip calculation
  5. tan(dip) = H/L where H=height diff, L=horizontal dist
tan(δ) = H / L
δ = true dip angle
H = height difference between strike lines
L = horizontal distance between them (⊥ to strike)

📌 Maps & Thickness Memory Box

  • t = w × sin(δ) — vertical outcrop, horizontal ground
  • V-shapes in valleys: V points upstream if dip < slope angle
  • 3-point problem: 3 boreholes → strike lines → dip angle
  • Strike lines = geological contours on a bed surface

💧 Water Velocity Controls Deposition

  • Fast (mountain streams) → Gravel
  • Moderate (lower rivers) → Sand & Silt
  • Slow (deep ocean) → Clay
  • Ice (glacier) → All sizes mixed (Till)

🔍 Diagenesis (Soil → Rock)

  • Compaction: weight of overburden squeezes voids
  • Cementation: minerals precipitate at grain contacts
  • Recrystallisation: minerals recrystallise under pressure
  • Result: porosity decreases, strength increases

🌡️ Regional Metamorphism of Mudstone/Shale

As pressure AND temperature increase progressively:

🔑 Key Properties to Remember

RockKey FeaturesGrade
SlateSlaty cleavage, breaks in sheetsLow
PhylliteShiny (mica), silky lustreLow-Mid
SchistSchistosity, flakey micas visibleMedium
GneissBanding, strong, large crystalsHigh

Bedding vs Cleavage in Slate

  • Original bedding = from sedimentary deposition
  • Cleavage = from metamorphic pressure (DIFFERENT direction)
  • Cleavage = closely spaced fractures ⊥ to pressure direction
  • In slate: cleavage and bedding are at different angles

Non-foliated Metamorphics

  • Marble = limestone metamorphosed (recrystallised calcite)
  • Quartzite = sandstone metamorphosed (recrystallised quartz)
  • Both strong, non-foliated
  • Hornfels = contact metamorphism of any rock, fine-grained, strong
🦴

Shale = clay rock. Bury it, squeeze it, heat it. First → Slate (breaks in sheets). More heat → Phyllite (shiny). More → Schist (sparkly minerals). Lots more → Gneiss (stripy, tough). Almost melt → back to igneous!

🧠 Which metamorphic rock shows banding and is the HIGHEST grade?

📌 Metamorphic Memory Box

  • Shale → Slate → Phyllite → Schist → Gneiss (increasing P&T)
  • Slate = low grade, splits easily (used for roofing)
  • Gneiss = high grade, banded, very strong
  • Marble = limestone metamorphosed. Quartzite = sandstone metamorphosed
  • Cleavage ≠ Bedding in slate (different directions)
  • Contact metamorphism = around intrusion (high T, low P) → Hornfels
  • Regional metamorphism = mountain chains (high T + high P)

Lecture 4 — Weathering, Karst & Stereonets
🏔️ Weathering Types & Grades I–VI
🔥 HIGH PRIORITY
▾

Physical Weathering (mechanical)

  • Freeze-thaw: water expands 9% when freezing → cracks widen (scree slopes)
  • Thermal expansion: repeated heating/cooling
  • Stress relief: unloading causes joints to open
  • Wetting/drying: swelling clays
  • Dominant in colder climates

Chemical Weathering

  • Solution: dissolution (e.g. calcite in limestone → karst)
  • Hydrolysis: feldspar → clay (kaolinite)
  • Oxidation: iron minerals → iron oxides (haematite)
  • Dominant in warmer, wetter climates (Hong Kong, Malaysia)
  • Key rule: Silicates → clays. Carbonates → go into solution. Quartz = resistant

Typical weathering profile (granite/volcanic rock)

⚠️ Corestones

  • Fresh rock cores preserved within highly weathered matrix
  • Form when joints are moderately spaced (not too close, not too far)
  • Grades I-II preserved as corestones in Grade IV-V matrix
  • Engineering significance: sudden change in stiffness!
🦴

Rock start fresh (Grade I). Rain and cold attack it from top. Joints get attacked first — round blobs of fresh rock survive inside (corestones). Outer rock turn to soil (Grade VI). Deep Hong Kong — 50m of weathering! Engineer must know: Grade I-II = rock. Grade IV-VI = soil for engineering. ROCKHEAD = boundary between.

📌 Weathering Grades Memory Box

  • I=Fresh → II=Slight → III=Moderate → IV=High → V=Complete → VI=Residual soil
  • Grades I-III = Engineering ROCK (treat as rock)
  • Grades IV-VI = Engineering SOIL (treat as soil)
  • ROCKHEAD = interface between rock and soil (often Grade III/IV boundary)
  • Corestones = fresh rock blobs in weathered matrix (Grade IV)
  • Chemical weathering: silicates→clays, carbonates→solution, quartz=resistant
🕳️ Karst — Sinkholes, Caves & Engineering Problems
🔥 HIGH PRIORITY
▾

💡 What is Karst?

Chemical weathering (dissolution) of limestone (and dolomite) by slightly acidic rainwater. CO₂ + H₂O = H₂CO₃ (carbonic acid) dissolves CaCO₃.

Dissolution is concentrated along joints → creates caves, sinkholes, underground drainage.

Karst Features

  • Sinkholes/Dolines: bowl-shaped depressions, can form suddenly
  • Caves: underground cavities along joints
  • Irregular rockhead: highly variable depth to limestone
  • Pinnacles: columns of limestone sticking up into overlying soil

⚠️ Engineering Problems

  • Sudden sinkhole collapse (e.g. Orlando, Florida 1981)
  • Dolines filled with soil — invisible from surface!
  • Foundations may be on irregular, unreliable rock surface
  • Seepage and water loss through caves
  • Need extensive site investigation: drilling + GPR + geophysics

📋 Classes of Karst (Severity)

  • Mild: surface weathering, few dolines
  • Moderate: dolines, irregular rockhead
  • Severe: extensive cavities, pinnacled rockhead, unpredictable
🦴

Rain is slightly acid. Limestone = calcium carbonate. Acid eat calcium carbonate. Water flow along cracks in rock → crack get bigger → cave form → cave roof collapse → SINKHOLE appear overnight! Scary for buildings.

Karst: acid rain dissolves limestone along joints
🧠 During site investigation for a bridge foundation on Carboniferous Limestone, you find the rockhead depth varies from 5m to 40m across just 50m distance. This MOST likely indicates:

📌 Karst Memory Box

  • Karst = limestone dissolved by carbonic acid (CO₂ + H₂O)
  • Dissolution along joints → caves, sinkholes, irregular rockhead
  • Sinkholes (dolines) can form suddenly — major engineering hazard
  • Dolines filled with soil = invisible from surface
  • Mendip Hills & Cheddar = classic UK karst example (past paper!)
  • Site investigation: need many boreholes + geophysics due to unpredictable rockhead
🎯 Stereonets & Slope Failure Mechanisms
🔥 HIGH PRIORITY
▾

💡 What is a Stereonet?

A 2D representation of 3D planes and lines. Projects the intersection of a plane with a reference sphere onto a flat surface (equatorial projection — lower hemisphere).

Key Representations

  • Great circle = intersection of plane with sphere = represents a plane
  • Pole = normal to the plane = point on sphere (90° from great circle)
  • Plot orientation as: dip direction/dip angle (e.g. 270/30)
  • Steep planes → great circle close to edge of net
  • Shallow planes → great circle close to centre

🔴 Three Failure Modes

1. Planar Sliding

  • Sliding on a single plane (bedding or joint)
  • Conditions: plane must daylight in slope face
  • Plane must dip less steeply than slope face
  • Plane must dip in roughly same direction as slope
  • On stereonet: great circle of joint INSIDE great circle of slope

2. Wedge Failure

  • Sliding on two intersecting planes simultaneously
  • Line of intersection must daylight in slope
  • On stereonet: intersection of two great circles falls inside slope great circle

3. Toppling Failure

  • Slabs rotate forward and overturn
  • Joints dip steeply INTO the slope (opposite to face)
  • On stereonet: pole of joint falls in toppling zone (near centre, opposite to slope dip)
Stereonet showing planar, wedge & toppling failure zones

🎯 Exam Stereonet Rules

  • Planar: Joint great circle INSIDE slope circle = potential sliding
  • Wedge: Intersection point of 2 joints INSIDE slope circle
  • Toppling: Joint pole in upper part, joint dips INTO slope
  • Always check if failure is kinematically possible first (geometry), then stability
🧠 On a stereonet, two joint sets are plotted. Their great circles intersect INSIDE the great circle of the slope face. What type of failure is kinematically possible?

📌 Stereonet Memory Box

  • Great circle = plane on stereonet (arc on net)
  • Pole = normal to plane (point on net, 90° from great circle)
  • PLANAR: joint great circle inside slope circle, same direction
  • WEDGE: intersection of 2 joint circles inside slope circle
  • TOPPLING: joint poles near centre-top; joints dip INTO slope
  • Always lower hemisphere projection!
  • Steep planes → great circle near edge; flat planes → near centre

🔢 Formula Hub

Every formula, with worked examples and exam recognition tips.

Apparent Dip Formula
📐 Use when: cross-section is NOT perpendicular to strike
tan(αapparent) = tan(αtrue) × cos(β)
αapparent = apparent dip [degrees]
αtrue = true dip [degrees]
β = angle between section direction and true dip direction [degrees]
✅ Worked Example

Given: True dip = 40°, β = 50°

tan(α_app) = tan(40°) × cos(50°)

= 0.839 × 0.643 = 0.539

α_app = arctan(0.539) = 28.3°

⚠️ Common Mistakes

  • Forgetting to take arctan at the end
  • Mixing up β definition (angle between section and DIP direction, not strike)
  • Apparent dip can NEVER exceed true dip
  • β = 0° → apparent = true. β = 90° → apparent = 0°
True Thickness of a Stratum
📐 Use when: finding real thickness from map outcrop width
t = w × sin(δ)
t = true thickness of layer [m]
w = map width of outcrop (perpendicular to strike) [m]
δ = true dip angle [degrees]
tan(δ) = H / L
H = vertical height difference between strike lines
L = horizontal distance between them (⊥ to strike)
✅ Worked Example

3-Point Problem:

Borehole A: depth to bed = 20m at elevation 100m → bed at 80m

Borehole B: depth = 30m at elevation 90m → bed at 60m

Borehole C: depth = 15m at elevation 95m → bed at 80m

Strike line through A and C (both at 80m elevation on bed)

H = 80-60 = 20m, L = distance A to B perpendicular

tan(δ) = 20/L → calculate L from map scale

✅ Thickness Example

Given: Outcrop width = 120m (perpendicular to strike), True dip = 25°

t = 120 × sin(25°)

= 120 × 0.423

t = 50.7 m

Note: If ground surface is not horizontal, use the full formula with ± ground slope correction

Shear Force on Sliding Plane (Simple)
⚡ Use when: basic slope stability calculation (planar failure)
ST = W sin(α)
ST = driving shear force [kN]
W = weight of sliding block [kN]
α = dip angle of sliding plane [degrees]
ST = VT cos(α)
VT = vertical component of weight
α = dip angle of failure plane

🎯 Exam Recognition

If asked about forces on a slope: draw the block, resolve forces parallel and perpendicular to the failure plane. Weight W acts vertically. Component parallel to plane = W sin(α) = driving force. Component perpendicular = W cos(α) = normal force.

Dip from Borehole/Map Data
📐 Use for 3-point problems and contour maps
tan(δ) = ΔH / L
δ = dip angle [degrees]
ΔH = difference in elevation of bed between two points [m]
L = horizontal distance between those points (⊥ to strike) [m]
✅ Step-by-Step: 3-Point Problem

1. Find elevation of bed at each borehole: elevation(surface) - depth

2. Find TWO boreholes with same bed elevation → draw strike line through them

3. Interpolate third borehole to find where same elevation strikes

4. Measure perpendicular distance from strike line to third point

5. Calculate: tan(δ) = ΔH / L, then δ = arctan(ΔH/L)

6. Dip direction: from higher elevation toward lower elevation (downslope)

Normal Fault (30-word answer)
  • "A normal fault is a dip-slip fault where the hanging wall (block above fault plane) has moved DOWN relative to the footwall."

Unconformity
  • "An unconformity is a surface representing a gap in the geological record, caused by erosion or non-deposition."
  • "An angular unconformity occurs where folded/tilted rocks are overlain by younger flat-lying strata."
  • "Indicates: deposition → deformation → erosion → renewed deposition."
Karst and Sinkholes
  • "Karst develops on limestone through dissolution by carbonic acid (CO₂ dissolved in rainwater)."
  • "Dissolution is concentrated along joints, forming caves, sinkholes (dolines), and irregular rockhead."
  • "Engineering problems: sudden sinkhole collapse, unpredictable foundation conditions, need for extensive SI."
Weathering Grades (Engineer's Answer)
  • "Weathering is graded I (fresh) to VI (residual soil) to describe degree of decomposition."
  • "Grades I-III treated as engineering rock; grades IV-VI treated as engineering soil."
  • "Rockhead = boundary between engineering soil and rock (typically grade III/IV boundary)."
  • "Corestones = fresh rock boulders within highly weathered matrix (grade IV)."
Metamorphic Sequence
  • "Regional metamorphism of mudstone with increasing pressure and temperature:"
  • "Mudstone/shale → slate (low grade, slaty cleavage) → phyllite (shiny surface) → schist (schistosity, coarse) → gneiss (high grade, banding)."
  • "Contact metamorphism around intrusions produces hornfels (high T, low P, non-foliated)."

How to answer the graph part

🧮 Bulk unit weight from cylinder dimensions
QUIZ STYLE
▾
V = \frac{\pi d^2}{4}h
d = cylinder diameter [m], h = height [m], V = sample volume [m³]
\rho = \frac{m}{V}, \quad \gamma = \rho g
m = sample mass [kg], ρ = density [kg/m³], γ = unit weight [N/m³ or kN/m³]

Key trap

  • Convert mm → m.
  • Convert g → kg.
  • Final γ usually in kN/m³, so divide N/m³ by 1000.
💧 Water content + Plastic Limit from lab masses
LECTURER FLAG
▾
w = \frac{M_w}{M_s}\times100 = \frac{M_{wet}-M_{dry}}{M_{dry}}\times100
Mw = water mass, Ms = dry soil mass, Mwet = wet sample mass, Mdry = oven-dry mass

Plastic Limit method

  • Calculate water content for each plastic-limit sample.
  • Average the valid values.
